# 使用説明書

外国人スタッフを受け入れている会社の総務担当者が、スタッフごとの在留期限と提出書類を一か所で管理し、期限切れや出し忘れを防ぐためのツールです。**架空のデータによるデモ**で、PDF・CSV は行政の正式様式ではありません。

## 何ができるか
| 機能 | 内容 |
|---|---|
| ダッシュボード | 在留期限90日以内・期限切れの人数、必須書類の未提出・期限切れ件数。期限の近い順の一覧 |
| スタッフ管理 | 登録・編集・検索・在留資格での絞り込み。退職は削除ではなく「退職」状態にする |
| 在留カード履歴 | 更新のたびに新しい行を追加（過去の履歴は残す）。カード番号は下4桁のみ |
| 書類チェックリスト | 書類ごとに 未提出 → 提出済み → 承認済み。期限を過ぎると毎日のチェックで「期限切れ」になる |
| 毎日の期限チェック | 90／60／30日前・期限切れの通知を作る。メールは送らず「送信予定メール（デモ表示）」として画面に出す |
| 出力 | 在留期限一覧PDF（A4横・日本語）、提出用CSV（Shift_JIS／UTF-8、和暦／西暦） |
| 組織設定（管理者のみ） | ユーザー、書類種別、組織名、期限チェックの「今すぐ実行」 |
| 監査ログ | 誰がいつ何を変えたかをデータベースに記録 |

## 使い方
1. `起動.bat` をダブルクリックします（初回は準備に数分かかります）。ブラウザでログイン画面が開きます。
2. デモ用アカウント（パスワードはすべて `demo-pass-2026`）でログインします。

   | アカウント | 立場 | 見え方 |
   |---|---|---|
   | `admin@demo-a.example` | 組織A「あおぞら製作所（架空）」の管理者 | すべての画面と設定 |
   | `member@demo-a.example` | 組織Aの担当者 | スタッフと書類の更新、PDF。設定とCSVは不可 |
   | `admin@demo-b.example` | 組織B「みなと物流（架空）」の管理者 | 組織Bのデータだけ。Aのデータは見えない |
3. ダッシュボードで期限の近いスタッフを確認し、名前からスタッフ詳細 → 書類チェックリストへ進みます。
4. 在留期限が更新されたら、スタッフ詳細の「在留カードを追加」で新しいカードを登録します。
5. 「出力」から在留期限一覧PDFを開けます。管理者は提出用CSVも取れます。
6. 止めるときは、起動.bat の黒い画面で Ctrl+C を押します。

## 試すと分かること
- 担当者でログインすると、設定メニューが出ず、URLを直接開いても403になる。
- 組織Bでログインすると、組織Aのスタッフは一覧にも検索にも出ない。Aのスタッフ詳細のURLを開くと404になる。
- 管理者で「今すぐ実行」を2回押しても、通知は二重に作られない。

## 制限事項
- デモ用です。登場する組織・人物・数値はすべて架空です。
- PDF・CSV は公的な届出の項目並びを参考にした独自様式で、行政の正式様式ではありません。
- メールは実際には送りません（画面表示のみ）。
- 毎日の期限チェックは常駐の仕組みではなく、起動時の1回・画面の「今すぐ実行」・`ruby bin/rails zairyu:daily` で動かします。
- パスワード再設定の機能はありません。
- お知らせ文のAI下書き（やさしい日本語化・翻訳）は今回の範囲に含めていません。
- Windows では、日本語を含むフォルダに置くと起動できないことがあります。英数字だけのパス（例：`C:\projects\zairyu-desk-rails-demo`）に置いてください。
- データベースは SQLite です（デモ・単一PC向け）。
